BLACKOUT: ZERO HOUR - Switch homebrew prototype

Requirements:
- Nintendo Switch running Atmosphere
- Homebrew Menu (hbmenu)
- A build produced by the GitHub Actions workflow

Install:
1. Download the BLACKOUT-ZERO-HOUR-NRO artifact from the Actions run.
2. Copy blackout-zero-hour.nro to SD:/switch/blackout-zero-hour/blackout-zero-hour.nro
3. Open Homebrew Menu and launch BLACKOUT: ZERO HOUR.

Controls:
- D-pad: move
- Plus: exit

This first build is a small playable libnx console prototype used to verify the Switch toolchain and input loop. It is NOT yet a 3D first-person shooter. The FPS renderer, original 3D assets, campaign, online services, local wireless, split-screen, and multiplayer systems remain future development work.
